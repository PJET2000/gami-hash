Hashing Tool

Create checksums of your collection, no technical knowledge needed

This small program creates a checksum list of the files in a folder you choose, so Authentic Memory can take over your collection safely. Your files are only read and never leave your institution.

Download for Windows
Version 1.2.0 · a single file, about 3 MB · no installation, no admin rights
  • ✓ Only reads your files. Nothing is changed, moved or deleted.
  • ✓ No internet use. No file contents leave your computer.
  • ✓ Stop any time. The next start continues where you left off.

Also available for macOS · Linux · all variants
On macOS and Linux: extract the archive with a double-click, then start the program inside.

How it works

  1. 1
    Download and double-click.

    Easiest is to keep the file on your desktop. There is nothing to install.

  2. 2
    Choose the folder.

    The program asks which folder (or external drive) should be recorded.

  3. 3
    Confirm where to save, then start.

    The program suggests your desktop and a file name for the result. Just click Save, then Start.

  4. 4
    Wait, or simply keep working.

    A progress bar shows the remaining time. Large collections can take hours. You can keep using the computer, or click Cancel and continue another day: the next start picks up right where it stopped.

  5. 5
    Send the result file to Authentic Memory.

    At the end the program offers to open the folder for you. Send the CSV file (file names and checksums only, no file contents) to your Authentic Memory contact as agreed.

    A step-by-step guide with pictures comes with our email.

Windows shows a blue message on first start?

"Windows protected your PC" is a standard message for software from small publishers, not a sign of a problem. Your IT can check the authenticity of the file at any time (see below).

Click More info, then Run anyway.

For your IT department

› Transparency & verification: source code, checksums, reproducible builds

The program is open source and contains no networking code at all. You can check this in the source code on GitHub or with any firewall. It only reads the chosen folder; the only thing it writes is the result file at the chosen location. A one-page overview ships with the software (WHAT-THIS-TOOL-DOES.md).
